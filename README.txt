军理刷题完全体 V4
=====================
已内置完整 2337 道题，不需要再导入题库。

核心功能：
- 手机优先 UI / 底部导航
- 2337题完整内置
- 单选、多选、判断、填空
- 多选严格匹配答案集合
- 随机 / 顺序 / 未练优先 / 错题专项
- 章节、题型、难度、数量筛选
- 即时判分 / 整卷考试模式
- 50题正式模拟 + 45分钟倒计时
- 答题卡、题号跳转
- 收藏
- 自动错题本
- 搜索题库
- 学习统计、章节完成度、最近14天记录
- 每日刷题目标
- 学习记录 JSON 导入/导出
- PWA manifest + Service Worker 离线缓存
- 添加到手机桌面

使用：
1. 解压。
2. 本地测试：在文件夹中运行 `python -m http.server 8000`
3. 电脑打开 http://127.0.0.1:8000/
4. 手机正式安装 PWA 建议部署到 HTTPS 网站。PWA 安装通常要求 HTTPS，或本机 localhost/127.0.0.1 开发环境。
